# Dolgator

Минималистичный счётчик калорий (граммы) и повторений в упражнениях. Личное приложение без сервера — все данные хранятся на телефоне.

## Стек

- **React Native** + **Expo 52**
- **AsyncStorage** — локальное сохранение
- TypeScript

## Быстрый старт

### 1. Установите Node.js

Скачайте LTS с [nodejs.org](https://nodejs.org/) (версия 20+), перезапустите терминал.

### 2. Установите зависимости

```bash
cd dolgator
npm install
```

### 3. Запуск на ноутбуке (браузер)

```bash
npm run web
```

Откроется в браузере — можно проверить логику и интерфейс.

### 4. Запуск на Android

```bash
npm start
```

- Установите **Expo Go** на телефон
- Отсканируйте QR-код из терминала

Или подключите эмулятор Android Studio и нажмите `a` в терминале Expo.

### 5. Сборка APK (позже)

```bash
npx eas build --platform android --profile preview
```

(Нужен аккаунт Expo и `eas-cli`.)

## Как пользоваться

### Упражнения (верх — фиолетовый)

1. Регулируйте повторения кнопками **−** и **+**
2. По очереди: **ноги → грудь → спина** (3 упражнения = 1 подход)
3. **Нажмите на таблицу** — записать текущее значение (кнопка ОК)
4. После 3-го упражнения подход целиком попадает в строку таблицы
5. Строка **суммы** — всего повторений за день

### Еда (низ — голубой)

1. Взвешивайте порцию, выставляйте граммы **−** / **+** (шаг 10 г)
2. **Нажмите на таблицу** — записать приём пищи
3. Максимум **5 приёмов** в день
4. Строка **сумма** — всего грамм за день

### Неделя

Колонки — дни текущей недели (пн–вс). Сегодняшний день подсвечен.
