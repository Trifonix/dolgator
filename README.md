# Dolgator

Минималистичный счётчик повторений в упражнениях и граммов пищи. Личное приложение без сервера — все данные хранятся на телефоне.

**Версия:** 1.0.2 Alpha · **Разработчик:** [Trifonix](https://t.me/trifonixwebsites)

![Эскиз интерфейса](main-screen.png)

## Стек

- **React Native** + **Expo 52**
- **AsyncStorage** — локальное сохранение
- **EAS Build** — сборка APK
- TypeScript

## Быстрый старт

### 1. Node.js

LTS с [nodejs.org](https://nodejs.org/) (версия 20+).

### 2. Зависимости

```bash
git clone https://github.com/<ваш-аккаунт>/dolgator.git
cd dolgator
npm install
```

### 3. Web-превью

```bash
npm run web
```

### 4. Android (Expo Go)

```bash
npm start
```

Установите **Expo Go**, отсканируйте QR-код.

### 5. Сборка APK

Проект уже привязан к EAS (`projectId` в `app.json`). Повторный `eas init` не нужен.

```bash
npx eas login
npm run build:apk
```

> Если загрузка падает с **403 Forbidden**, включите VPN (блокировка Google Cloud) и повторите сборку.

APK скачивается по ссылке из терминала или на [expo.dev/accounts/trifonix/projects/dolgator](https://expo.dev/accounts/trifonix/projects/dolgator).

Перед каждым релизом обновите:
- `src/version.ts`, `src/changelog.ts`, `CHANGELOG.md`
- `app.json` → `version` и `android.versionCode` (+1)

Запись в changelog — **по категориям** (разбор коммитов с прошлого релиза):
- **Глобальные обновления** — экраны, архитектура, редизайн
- **Фичи** — новое поведение
- **Патчи** — баги и мелкие правки

Подробнее: шапка `CHANGELOG.md` и `.cursor/rules/release-changelog.mdc`.

Локальная сборка (нужны JDK 17 + Android Studio):

```bash
npm run build:apk:local
```

## Как пользоваться

### Первый запуск

При отсутствии данных открывается стартовый мастер:

1. Приветствие
2. **Повторения** — 15 подходов за один день прошлой недели (или «Использовать пример»)
3. **Питание** — до 5 приёмов (или пример 250-400-500)

Один день дублируется на другие дни прошлой недели с разбросом. На главном экране прошлая неделя — **бледно-серым** в таблице текущей. Цели: **+3 %** повторений и **−~10 г** питания в неделю.

### Колбы (центр)

- **Слева (ПОВТОРЫ, 3 канала)** — стеклянная пробирка; засечки 60% и 80%. Заливка слоновая кость, 3 с, затем 1 с вспышка статуса: красный / жёлтый / зелёный. Высота = служебный блок.
- **Справа (ГРАММЫ)** — та же эстетика. 100% = среднесуточное прошлой недели. Зелёный <96%, жёлтый 96–100%, красный ≥100%.

### Упражнения (верх — фиолетовый)

1. **− / +** — выставить повторения
2. **Тап по числу** → «Вы сделали N повторений?» → **Да**
3. Сначала **5 подходов ног**, затем **5 грудных**, затем **5 спины** — каждое значение сразу в мини-колонку сегодня
4. После 15-го подхода число **60 с** бледно-красное: двойной тап снимает последний подход; затем снова тёмно-серое. **10 быстрых тапов** по числу снова включают режим удаления на 60 с
5. **5 тапов по таблице** → очистка данных за сегодня

### Еда (низ — голубой)

1. **− / +** — граммы (шаг 10 г)
2. **Тап по числу** → «Вы съели N грамм?» → **Да**
3. До **5 приёмов** в день
4. После 5-го приёма число **60 с** бледно-красное: двойной тап снимает последний приём; затем снова тёмно-серое. **10 быстрых тапов** по числу снова включают режим удаления на 60 с
5. **5 тапов по таблице** → очистка

### Прочее

- Колонки **сб–вс** — другой фон (выходные)
- Угол под «5» — сравнение сумм текущей и прошлой недели
- **История изменений:** 5 тапов верхняя таблица → Нет → 5 тапов нижняя → Нет

## Публикация на GitHub

```bash
# создайте пустой репозиторий на github.com, затем:
git remote add origin https://github.com/<ваш-аккаунт>/dolgator.git
git push -u origin main
```
